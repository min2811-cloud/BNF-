# BNF 매매법 앱 사용 설명서

우량 대형주가 단기 급락했을 때 저점매수 신호를 잡아주는 보조 도구입니다.
**실제 주문은 이 앱이 하지 않습니다.** 신호만 보여주면 사장님이 직접 증권사 앱에서
사고 파는 방식입니다.

## ⚠️ "토큰" 관련 오해 방지

- 이 앱을 켜놓고 버튼을 누르는 동안 **Claude(AI)는 한 번도 호출되지 않습니다.**
  전부 파이썬 코드로 직접 계산합니다. 그래서 AI 사용 비용(토큰)이 전혀 들지 않습니다.
- 다만 한국투자증권 API 안에는 "access_token"이라는 게 있는데, 이건 그냥
  "내가 인증된 사용자다"를 증명하는 24시간짜리 출입증 같은 것이지 돈이 드는 게
  아닙니다. 완전히 다른 개념이니 헷갈리지 않으셔도 됩니다.

## 시작하기 전에 준비할 것 (한 번만 하면 됨)

1. **한국투자증권 계좌** — 없으면 앱/홈페이지에서 비대면으로 개설 (시세 조회만
   쓸 거라 주문 권한은 필요 없어요)
2. **한투 Open API 신청** — 한투 홈페이지 > Open API 서비스 신청 → App Key,
   App Secret 발급 (이 두 값을 나중에 앱에 입력해요)
3. **구글 계정** — 시트를 데이터 저장용으로 쓸 거예요
4. **GitHub 계정** — 앱을 무료로 인터넷에 올릴 때 필요해요

이 4가지가 구체적으로 어떻게 하는지는 처음 배포할 때 Claude가 화면 단계별로
안내해드릴게요.

## 로컬에서 먼저 테스트하는 법

```
pip install -r requirements.txt
```

`.streamlit/secrets.toml.example`을 복사해서 `.streamlit/secrets.toml`로 저장하고
안의 값들을 실제 값으로 채운 다음:

```
streamlit run app/main.py
```

브라우저가 자동으로 열리면서 앱이 뜹니다. 3개 탭을 하나씩 눌러보면서 잘 되는지
확인해보세요.

## 폰으로 어디서든 접속하기 (배포)

1. 이 폴더를 GitHub private 저장소에 올림
2. https://share.streamlit.io 에서 GitHub 계정으로 로그인 → New app →
   방금 올린 저장소 선택, 실행 파일은 `app/main.py`로 지정 → Deploy
3. 배포된 앱 설정(Settings) > Secrets 메뉴에 `secrets.toml.example`에 채워넣은
   내용을 그대로 붙여넣기
4. 앱 설정 > "Who can view this app"에서 사장님 이메일만 허용하도록 제한 (이중 보안)
5. 이제 폰 브라우저에서 배포된 주소로 들어가면 어디서든 접속 가능

## 화면 사용법 (사장님 매매 규칙, 2026-10-03 확정)

하루 흐름: **오전 10시 스캔 → 오후 2시 50분 매수 확인 → 보유 종목에서 매도 알림 확인**

- **🏆 우량주 추천**: 코스피 시가총액 상위 200개 우량주 목록. 하루 한 번.
- **📉 급락 스캔·매수**
  - **① 오전 10시 급락 스캔**: "급락 종목 찾기"를 누르면 우량주 중 전일 대비 -5% 이하
    종목을 찾아서 구글시트(`scans` 탭)에 저장해요. 폰을 껐다 켜도 남아 있어요.
  - **② 오후 2시 50분 매수 확인**: "지금 매수 대상 확인"을 누르면 10시 종목을 다시 조회해서
    지금도 -5% 이하인 종목만 "매수 대상"으로 보여줘요. 수량(100만원 이내, 1주가 넘으면 1주),
    금액, 손절가(-4%), 익절가(+10%), 매도 예정일까지 계산해줘요.
    코스피도 -1% 이상 같이 빠졌는지(✅ 시장 같이 하락 / ⚠️ 혼자 하락)도 참고로 표시해요.
  - 두 표 모두 BNF 원래 지표(이격도·RSI·MACD, "✅ 충족" = 이격도 80 이하 + RSI 30 미만 +
    MACD 양수)를 참고용으로 같이 보여줘요. 매수 대상 표의 지표는 확인 시점 가격으로 다시 계산해요.
  - 증권사 앱에서 실제로 샀으면 아래 폼에 체결가·수량을 넣고 "보유 종목으로 등록".
- **💼 보유 종목**: "전체 현재가 새로고침" 한 번이면 모든 종목의 수익률·손익과 함께
  🔴 손절(-4% 도달) / 🟢 익절(+10% 도달) / 🟡 오늘 매도일 / 🟠 매도일 지남 알림이 떠요.
  매도 예정일은 매수일로부터 3거래일 뒤(월→목, 금→수, 휴일 끼면 그만큼 연장).
  팔았으면 "매도 완료 처리"에서 매도가를 넣고 목록에서 빼주세요(기록은 시트에 남아요).

앱은 알림만 하고 **자동으로 주문하거나 실시간으로 감시하지는 않아요.** 장중 -4%·+10%를
놓치지 않으려면 증권사 앱의 "자동 감시주문(스탑로스)"을 같이 걸어두는 걸 추천해요.

## 기준값을 바꾸고 싶다면

`app/config.py` 파일 하나에 모든 기준값(급락 -5%, 종목당 100만원, 손절 -4%, 익절 +10%,
보유 3거래일 등)이 모여 있어요. 임시공휴일이 생기면 `app/trading_days.py`의
`EXTRA_CLOSED_DAYS`에 날짜를 추가하세요. 이 숫자만 바꾸면 앱 전체에 반영됩니다.
