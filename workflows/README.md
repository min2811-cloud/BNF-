# workflows/

여기에는 반복 업무 하나당 파일 하나씩, 쉬운 말로 쓴 단계별 지시서가 들어간다.

새 Workflow 파일을 쓸 때는 아래 항목을 채운다.

- **목표**: 이 업무가 끝나면 뭐가 나와야 하는지
- **필요한 입력값**: 시작하기 전에 사장님한테 받아야 할 정보
- **실행할 Tool**: `tools/` 폴더의 어떤 파일을 쓰는지
- **결과물 형태**: 구글 시트/Gmail/드라이브 중 어디로, 어떤 모습으로 나가는지
- **문제 발생 시 대응**: 자주 터지는 문제와 그때 어떻게 하는지

Workflow는 조직의 지식이다. 더 나은 방법을 찾으면 업데이트하되, 사용자 허락 없이 새로 만들거나 지우지 않는다.
